# Service Requests

מערכת לניהול פניות ובקשות שמתקבלות מארגונים ומעסיקים: חיפוש, סינון ועדכון סטטוס, עם הגנה מעדכונים מתחרים, היסטוריית שינויים ונתונים מסכמים.

**טכנולוגיות:** .NET 10 · ASP.NET Core · EF Core · SQL Server · Angular · Angular Material

> הפרויקט בפיתוח. הוראות הרצה, מדריך לבודק ותיעוד מלא יתווספו כאן.
